# 창원시 전기차 충전소 추천 MVP (팔용동 · 중앙동 · 석동)

## 1. 프로젝트 개요
경상남도 창원시 **의창구 팔용동, 성산구 중앙동, 진해구 석동** 거점을 대상으로, 사용자의 현재 SOC, 목표 SOC, 배터리 용량, 차량 최대 수용 출력, 예상 체류 시간, 이용 시간대, 계절 시나리오를 반영해 **총 소요 시간(추가 이동 + 예상 대기 + 예상 충전)** 기준 최적 충전소와 대체 충전소를 추천하는 웹 MVP입니다.

## 2. 저장소 구조
- `index.html`: 대시보드 화면 및 스크립트 진입점
- `js/data.js`: 거점 샘플 데이터, 시간대/계절 시뮬레이션 상수, 한국환경공단 API 응답 매핑
- `js/calculator.js`: 입력 검증, 필요 충전량(kWh), SOC 구간별 충전 시간(분), 대기 시간(분) 계산
- `js/recommender.js`: 추천 점수 산정, 최적/대체 충전소 선정, 피크 시간대 수요 분산 시뮬레이션
- `js/ui.js`: 추천 카드, 대체 충전소, 수요 분산 표, 필터/정렬 테이블 렌더링
- `js/app.js`: UI 이벤트 연결 및 API 호출 제어
- `test/run-tests.js`: 계산·예외 처리·추천 로직 단위 테스트

## 3. 실행 및 테스트 방법
- **웹 대시보드 실행:** GitHub Pages를 활성화하거나 `index.html`을 브라우저로 엽니다.
- **단위 테스트 실행(Node.js):** 터미널에서 `node test/run-tests.js` 실행 시 `ALL TESTS PASSED`가 출력됩니다.

## 4. 데이터 구분 안내
- **실제 API 옵션:** 공공데이터포털 한국환경공단 전기차 충전소 정보 API 키를 입력하면 상태·출력·갱신시각 데이터를 반영할 수 있습니다.
- **시뮬레이션/가정값:** 시간대별 가동률, 계절 보정(+15%p 등), 초기 기준(가동률 60% 미만, 추가 이동 5분 이내), 수요 분산 수치(90% → 65% 이하 목표)는 알고리즘 검증용 가정값이며 실제 측정치가 아닙니다.
